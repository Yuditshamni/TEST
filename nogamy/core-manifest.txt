# core-manifest.txt — what is core (Nogamy) in every project.
#
# Core paths are read-only in a project. Three things read this file:
#   nogamy/ops/core_sync.py      a core update replaces exactly these paths (skill nogamy-core-update)
#   nogamy/ops/core_guard.py     the PR check fails when a core file differs from the released core
#   nogamy/hooks/nogamy_hook.py  the agent hook blocks editing them (Claude Code, Copilot, Codex)
#
# Syntax, one entry per line:
#   path/file.md     one file
#   folder/          the whole folder, recursive
#   a/b-*/  a/*.yml  `*` matches inside one path segment
#   !path            exception: not core, even inside a core folder
# Everything not listed is project-owned and is never touched by a core update.
# Project-owned skeletons (PROJECT.md, README.md, _context/*.md, CODEOWNERS, .core-version)
# come once with "Use this template" and are never synced.
# Files that exist only in the core repo: nogamy/core-only.txt (removed from projects on update).
# Platform files (Fabric): nogamy/packs/, added per project with nogamy-add-pack.
